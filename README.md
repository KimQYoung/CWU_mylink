# CWU_mylink (마이링크)

2학년 2학기 수강한 "아이디어를현실로-바이브코딩(사)"에서 진행한 프로젝트 레포지토리

---

## 🚀 프로젝트 소개
- **프로젝트명**: 마이링크 (MyLink)
- **기술 스택**: Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS

---

## 🛠️ 시작하기

개발 서버 실행:

```bash
npm run dev
```

브라우저에서 [http://localhost:3000](http://localhost:3000)으로 접속하여 결과를 확인할 수 있습니다.

빌드 및 배포:

```bash
npm run build
npm run start
```
