# [와이어프레임] 마이링크 메인 사용자 화면 (Main Profile Wireframe)

> **문서 버전**: v1.0.0  
> **대상 화면**: 방문자/사용자가 열람하는 메인 공개 프로필 페이지 (`/` 및 `/[username]`)  
> **디자인 규격**: xAI Minimal Dark (`DESIGN.md` 기반)  
> **상태 저장소**: LocalStorage (Zustand 동적 연동)

## 3. UI 컴포넌트별 상세 스펙 및 인터랙션 매핑

| 번호 | 컴포넌트명 | 시각적 특징 및 디자인 토큰 | 인터랙션 및 상태 제어 |
|:---:|---|---|---|
| **[1]** | **Sticky Header** | • 배경 `#0a0a0a/90` 백드롭 블러<br>• 하단 1px 헤어라인 테두리 (`#212327`)<br>• 우측 초록색 펄스 인디케이터 | 스크롤 시 상단 고정. LocalStorage 연결 상태 실시간 표시 |
| **[2]~[4]** | **Hero & Intro** | • 대문자 모노 주석체 (`GeistMono`, +1.4px 자간)<br>• 48~96px 기하학 디스플레이 폰트 (-0.035em 음수 자간)<br>• Bold 없이 Weight 400 일괄 적용 | LocalStorage의 `name`, `headline` 데이터 자동 바인딩 |
| **[5]** | **Profile Card** | • 64px 원형 프로필 아바타 (헤어라인 보더)<br>• 3단 그리드 메타데이터 (`CALLSIGN`, `DISCIPLINE`, `STATUS`) | LocalStorage의 프로필 메타데이터 실시간 반영 |
| **[6]** | **Statement** | • 상단 헤어라인 디바이더<br>• 국문/영문 겸용 2단계 폰트 크기 계층 | 개발자의 비전 및 철학 텍스트 전달 |
| **[8]** | **Link Cards** | • 모바일: 버튼이 카드 하단에 100% 너비로 배치<br>• 데스크톱: 우측 인라인 배치<br>• 아웃라인 필(9999px) & 화이트 필(Primary) | • 외부 URL 클릭 시 새 탭 이동 (`target="_blank"`)<br>• 이메일 클릭 시 클립보드 복사 + 토스트 알림 |
| **[9]** | **Capabilities** | • 모바일 1열 / 데스크톱 2열 그리드<br>• 카테고리 라벨 + 헤드라인 + 기술 스택 설명 | 개발자의 핵심 기술 역량 구조화 표시 |
| **[10]** | **Footer & Toast** | • 저작권 및 xAI 디자인 명시<br>• 우측 하단 미니멀 플로팅 토스트 | 복사 이벤트 완료 시 2.4초간 토스트 노출 후 자동 페이드아웃 |
